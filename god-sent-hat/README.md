# God Sent dad hat (matches the "God Sent" Christian graphic tee)

Blank: Printful Classic Dad Hat, Yupoong 6245CM (about $14.02 base cost).
Placement: front embroidery. Files are 1500 × 525 px, transparent PNG, 300 DPI (5" × 1.75").

Each file uses one thread colour. Strokes are kept thick so they stitch cleanly at hat size.
`mockups/` shows each design on the hat colours. These are rough previews, so use Printful's own mockup generator for the listing photos.
Fonts: Pacifico and Playfair Display (SIL Open Font License, free for commercial use).

## Printful setup
1. Product Templates → Classic Dad Hat (Yupoong 6245CM) → Embroidery → Front.
2. Upload the white-thread file for dark hats and the black-thread file for light hats, then centre it.
3. In the thread colour picker, choose White (#FFFFFF) or Black (#000000).
4. Embroidery digitization is a one-time fee per design. Check the current amount in Printful.
